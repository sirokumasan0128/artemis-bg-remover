# Installation

## Prerequisites

- Python 3.11+
- Recommended: A virtual environment

## Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/DIAMONDFANTASY/artemis-bg-remover.git
   cd artemis-bg-remover
   ```
   *(Note: The repository URL will be active once the project is public under the company account.)*

2. **Create a virtual environment**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows, use .venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
